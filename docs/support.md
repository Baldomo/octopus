# Support

Open an issue on the [issue tracker](https://github.com/zabealbe/octopus/issues) for a question, a bug or a request. A bug report helps most when it names the app and its version, the device and its OS, what you did, what you expected and what happened instead.

## Common questions

**The app can't reach my server.** The server must be running on a computer that's on and online. Open the server's menu on that computer to check it is reachable, then pair again from Show pairing code if the invite has expired. An invite stays open for 10 minutes.

**How do I add another device?** On a device that's already paired, open the client menu and choose Link a device, then scan its code with the new device.

**How do I remove a device or a teammate?** Open the server's menu on a paired device; it lists each account, each with Revoke.

**Where is my data stored?** On your own computers. See the [privacy page](privacy.md).
